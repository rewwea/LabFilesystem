# Лабораторная работа: Работа с `std::map` и файловой системой (`std::filesystem`) на C++

## Описание

Этот проект изначально был создан для демонстрации базовых операций с файловой системой через библиотеку `<filesystem>` (например, создание директорий, файлов, их копирование и удаление). Однако позже проект был-expanded и дополнен функциональностью работы с контейнером `std::map` для хранения данных о файлах и их размерах.

Теперь проект включает следующие возможности:
1. Рекурсивный обход каталога и заполнение `std::map` данными о файлах.
2. Сохранение данных из `std::map` в текстовый файл.
3. Загрузку данных из файла обратно в `std::map`.
4. Поиск файла по имени и вывод его размера.

---

## История проекта

Изначально этот проект фокусировался только на базовых операциях с файловой системой. Однако в рамках новой лабораторной работы он был расширен для демонстрации использования `std::map` и работы с файлами для сохранения и загрузки данных.
